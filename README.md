# انتشار: المرجع الموحّد لمنصة تطبيقات متاجر زد

هذا المستودع هو **المصدر الوحيد للحقيقة (Single Source of Truth)** لمشروع «انتشار» (الاسم الرمزي، و`intishar` في الكود): المتطلبات، والقرارات، والتصميم، والمهام، والتقدم.

> القاعدة: ما ليس مكتوبًا هنا غير موجود. وأي تغيير على ما اعتُمد يمر عبر [طلب تغيير](docs/process/change-request.md).

## من أين تبدأ

| الدور ([التعريف](docs/process/roles.md)) | ابدأ من |
|---|---|
| المعتمِد | [قرارات المنتج](docs/open-decisions.md)، ثم [وثيقة المنتج PRD](docs/01-prd.md) |
| المشرف | [التقدم](docs/progress.md)، و[خارطة الطريق](docs/roadmap.md)، و[فهرس الوثائق](docs/README.md) |
| المنفذ | [فهرس الوثائق](docs/README.md)، ثم [سجل القرارات المعمارية](docs/adr/README.md) |

## بوابة المشروع

موقع يُولَّد من هذا المستودع بـ VitePress ([ADR-0001](docs/adr/0001-docs-as-code-ssot.md))، ويعرض الوثائق بالعربية وصفحة التقدم والجدول الزمني.

```bash
npm install
```

```bash
npm run docs:dev
```

ثم افتح http://localhost:5173. صفحة التقدم تقرأ [GitHub Issues](https://github.com/mohammedALrabeai/intishar/issues) عبر `gh auth token` أو المتغير `GITHUB_TOKEN`. والنسخة المنشورة الخاصة تأتي في المهمة T-010.

## هيكل المستودع

```
README.md            ← هذا الملف
index.md             ← الصفحة الرئيسية للبوابة
docs/                ← حزمة المواصفات (المرجع الملزم)
  README.md          ← فهرس الوثائق وحالة كل وثيقة
  progress.md        ← التقدم والجدول الزمني
  roadmap.md         ← المراحل والبوابات
  01-prd.md          ← متطلبات المنتج
  open-decisions.md  ← قرارات المنتج
  inbox.md           ← الملاحظات الجديدة، والمؤجل، والمخاطر
  spikes.md          ← تجارب تقنية تحسم المجهول قبل التسليم
  adr/               ← سجل القرارات المعمارية
  modules/           ← مواصفات وحدات النظام (15 وحدة)
  process/           ← الأدوار، ومراجعة الخطة، وDoR وDoD، وطلب التغيير، وقالب القصة
reports/             ← تقارير البحث (مدخلات، ليست مواصفات ملزمة)
research_notes/      ← ملاحظات البحث الخام ومصادرها
.vitepress/          ← إعداد البوابة وصفحة التقدم
```

## الفرق بين البحث والمواصفات

- **`reports/` و`research_notes/`**: ما وجدناه وما أوصينا به. مرجع للفهم، لا يُنفَّذ منه مباشرة.
- **`docs/`**: ما قررناه واعتمدناه. هذا وحده ما يُوزَّع منه العمل على المنفذ.
