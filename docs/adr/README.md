# سجل القرارات المعمارية (ADR)

كل قرار تقني جوهري يُكتب هنا مرة واحدة، مع سببه وبدائله. الغرض ألا يُعاد النقاش فيه أثناء التنفيذ. والقرار المقبول لا يُعدَّل، بل يُستبدل بقرار جديد يشير إليه.

| الحالة | المعنى |
|---|---|
| مقترح | مكتوب ومسنود بالبحث، وينتظر اعتماد المعتمِد أو المشرف |
| مقبول | ملزم للتنفيذ |
| مستبدل | حلّ محله قرار أحدث (يُذكر رقمه) |

## قالب قرار جديد

```markdown
# ADR-XXXX: عنوان القرار

- الحالة: مقترح | مقبول | مستبدل بـ ADR-YYYY
- التاريخ: YYYY-MM-DD
- مرتبط بـ: F-xx, SPK-xx, D-xx

## السياق
ما المشكلة، وما القيود والحقائق التي تفرض القرار؟

## القرار
ما الذي قررناه، بصيغة ملزمة وواضحة.

## البدائل المرفوضة
كل بديل، ولماذا رُفض.

## العواقب
ما يصبح أسهل، وما يصبح أصعب، وما يجب مراقبته.

## المصادر
```
