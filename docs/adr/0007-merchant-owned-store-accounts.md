# ADR-0007: النشر على حسابات المطوّر الخاصة بكل تاجر

- الحالة: مقترح
- التاريخ: 2026-11-10
- مرتبط بـ: SPK-14

## السياق
تقضي إرشادة Apple 4.2.6 بأن يقدّم مزوّد المحتوى تطبيقات القوالب بنفسه، وتوصي Google بحساب لكل عميل. هذا القيد يحدد تصميم التوقيع والنشر والإشعارات.

## القرار
1. كل تاجر يملك حساب Apple Developer وGoogle Play، ويُفضَّل أن يكون حساب منظمة، ويدعو المنصة عضوًا.
2. المنصة تستخدم مفتاح API لكل تاجر (App Store Connect API key وPlay service account)، ويُحفظ في خزنة أسرار معزولة لكل تاجر. ولا تُطلب كلمة مرور Apple ID أبدًا.
3. التاجر يوافق على كل تقديم للمراجعة من لوحة التحكم.
4. مفتاح APNs لكل تاجر يُنشأ من فريقه هو.
5. اسم التطبيق ووصفه ولقطاته فريدة لكل تاجر، وتتولد آليًا من المعاينة.

## العواقب
- الإعداد الأول للتاجر أطول بأسبوعين إلى خمسة أسابيع، بسبب D-U-N-S والتحقق. لذا يحتاج المنتج معالج إعداد عربيًا (F-M10).
- يجب أن يدعم خط البناء توقيعًا مختلفًا لكل تاجر.
