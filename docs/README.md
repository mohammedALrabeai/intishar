## اصطلاحات

- **اللغة**: الوثائق بالعربية، والمصطلحات التقنية وأسماء الملفات والمعرّفات والكود بالإنجليزية.
- **المعرّفات**: المتطلبات `F-xx`، والقرارات المعلّقة `D-xx`، والتجارب `SPK-xx`، والقرارات المعمارية `ADR-xxxx`، وطلبات التغيير `CR-xxx`. المعرّف لا يُعاد استخدامه أبدًا.
- **الأولوية**: MoSCoW. Must لازم للإطلاق، وShould مهم لكن يحتمل التأجيل، وCould إضافة، وWon't خارج هذا الإصدار.
