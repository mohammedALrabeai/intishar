# قالب القصة (User Story)

```markdown
## [F-xx] عنوان القصة قصيرًا

**بصفتي** متسوقًا | تاجرًا | عضوًا في فريق المنصة
**أريد** …
**حتى** …

### معايير القبول
1. **بافتراض** … **عندما** … **إذن** …
2. **بافتراض** … **عندما** … **إذن** …
3. (حالات الخطأ والحالات الحدية)

### التصميم
- Figma: <رابط الإطار> (الحالات: محتوى، وفارغة، وتحميل، وخطأ، وعربي، وإنجليزي)

### العقد التقني
- Endpoint أو كتلة: `GET /api/v1/...` ← `06-api/...`
- أحداث التحليلات: `event_name { props }`

### التبعيات
- قصة أو مهمة سابقة، أو SPK-xx

### خارج نطاق هذه القصة
- …
```

## مثال

```markdown
## [F-S08] شريط الشحن المجاني في السلة

**بصفتي** متسوقًا
**أريد** أن أرى كم بقي لي حتى أحصل على شحن مجاني
**حتى** أضيف منتجًا وأوفّر الشحن

### معايير القبول
1. بافتراض أن للمتجر قاعدة شحن مجاني بحد 200 ريال، وأن مجموع السلة 155 ريالًا،
   عندما أفتح السلة، إذن يظهر «باقي لك 45 ر.س للشحن المجاني» مع شريط تقدم عند 77%.
2. بافتراض أن المجموع 200 ريال أو أكثر، عندما أفتح السلة، إذن يظهر «شحنك مجاني» ويمتلئ الشريط.
3. بافتراض أن المتجر بلا قاعدة شحن مجاني، عندما أفتح السلة، إذن لا يظهر الشريط إطلاقًا.

### العقد التقني
- `GET /api/v1/cart` ← `free_shipping_rule.subtotal_condition.remaining`
```
