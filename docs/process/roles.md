# الأدوار

> حُسم في D-03 بتاريخ 2026-11-10.

الفريق دوران تنفيذيان، ودور ثالث اختياري للاعتماد. ولا يوجد دور مصمم ولا مختبر مستقل. لذلك يتولى المشرف التصميم المرجعي والتحقق، ويُعوَّض الباقي بأدوات جاهزة وأتمتة (D-08).

| الدور | يملك | يقرر | لا يفعل |
|---|---|---|---|
| **المعتمِد** (اختياري، دور أعلى) | الاعتماد النهائي | عبور البوابات من G0 إلى G4، وقبول ADRs، وطلبات التغيير التي تمس النطاق أو المدة | لا يكتب المواصفات، ولا يوزع المهام |
| **المشرف** | حزمة المواصفات، والـ Backlog، والتقدم | الإجابة عن التوضيحات، وتوزيع المهام، وقبول القصص، وطلبات التغيير التي لا تمس النطاق ولا المدة. ويقوم بدور المعتمِد إن لم يوجد | لا يغيّر قرارًا معتمدًا دون طلب تغيير |
| **المنفذ** | الكود والاختبارات الآلية | كيف يكتب الكود، ضمن الدليل الهندسي والـ ADRs | لا يضيف ميزة، ولا يغيّر سلوكًا أو تصميمًا، ولا يحسم سؤال منتج بنفسه. يرفع السؤال إلى المشرف |

## من يفعل ماذا في الدورة

| الخطوة | المسؤول |
|---|---|
| كتابة القصص ومعايير القبول | المشرف، بمساعدة Claude |
| التحقق من DoR قبل التسليم | المشرف |
| التنفيذ والاختبارات الآلية وفتح PR | المنفذ |
| مراجعة الكود والتحقق من معايير القبول على staging | المشرف |
| تحديث حالة المهمة | المنفذ عند البدء وفتح PR، والمشرف عند القبول |
| تحليل أثر طلب التغيير | المشرف مع المنفذ |
| توقيع البوابات | المعتمِد، أو المشرف عند غيابه |
