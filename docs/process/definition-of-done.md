# Definition of Done: متى تُعد المهمة منجزة

تنطبق على **كل** قصة أو مهمة، لا على المشروع كله. أما شروط اكتمال المشروع فهي شروط الخروج (Exit Criteria) في `08-test-plan.md`.

- [ ] الكود مراجَع ومعتمد في Pull Request مرتبط بالـ Issue.
- [ ] الاختبارات الآلية تمر: unit وwidget للتطبيق، وfeature للخادم، واختبارات العقد لمخططات الكتل إن تغيرت.
- [ ] معايير القبول كلها تحققت على بيئة staging، وتحقق منها المشرف.
- [ ] الشاشة تعمل بالعربية (RTL) والإنجليزية، وبالوضعين الفاتح والداكن إن كانت من الواجهة.
- [ ] لا انهيارات جديدة في Sentry، ولا تراجع في ميزانيات الأداء.
- [ ] أحداث التحليلات المطلوبة تُرسل.
- [ ] الوثائق محدّثة إن تغير عقد: `06-api/`، أو الـ ADR، أو الدليل الهندسي.
- [ ] مدموج في الفرع الرئيسي ومنشور على staging.
- [ ] المشرف قبِل القصة في مراجعة السباق.
