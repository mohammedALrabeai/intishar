# Definition of Ready: متى تُسلَّم القصة للمطوّر

لا تدخل قصة إلى السباق إلا إذا تحققت كل البنود التالية. وإن نقص بند عادت القصة إلى المشرف، ولا يجتهد المطوّر في سدّه.

- [ ] مرتبطة بمعرّف متطلب في PRD (`F-xx`) وبـ Epic.
- [ ] مكتوبة بصيغة القصة: «بصفتي… أريد… حتى…». انظر [القالب](user-story-template.md).
- [ ] معايير قبول بصيغة Given/When/Then تغطي المسار الناجح والأخطاء والحالات الحدية.
- [ ] رابط Figma للشاشة بكل حالاتها: محتوى، وفارغة، وتحميل، وخطأ، وبالعربية والإنجليزية.
- [ ] العقد التقني محدد: الـ endpoint أو مخطط الكتلة في `06-api/`، والحقول، وأمثلة الاستجابة.
- [ ] التبعيات منجزة، أو لها بديل وهمي (mock) متفق عليه.
- [ ] لا تعتمد على تجربة حرجة مفتوحة في `spikes.md`.
- [ ] أحداث التحليلات المطلوبة مسماة.
- [ ] مقدّرة الحجم، ولا تتجاوز سباقًا واحدًا. وإن تجاوزت تُقسَّم.
- [ ] لا يوجد فيها قرار منتج معلّق.
