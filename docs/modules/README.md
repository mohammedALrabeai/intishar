## حدود المسؤولية بين الوحدات

- **M03 مقابل M11**: M03 يعرّف الكتل ورسمها في التطبيق وعقد JSON لكل كتلة. وM11 يخزّن الصفحات والنسخ وينشرها ويقدّمها.
- **M06 مقابل M07**: M06 يرسل الإشعار ويحمل فيه رابطًا. وM07 يملك صيغة الروابط والموجّه الذي يفتح الشاشة.
- **M08 مقابل البقية**: كل وحدة تعلن أحداثها في مواصفتها، وM08 يملك التصنيف الموحّد والجمع والتقارير.
- **M10 مقابل M05**: M10 يملك الاتصال بـ Merchant API وحدوده. وM05 يستخدمه لتفاصيل الطلب عبر الخادم الوسيط.
- **M13 مقابل M14**: M14 يجمع بيانات التاجر وحساباته ومفاتيحه. وM13 يبني ويوقّع ويرفع.
- **M15 مقابل البقية**: M15 يملك هيكل اللوحة ونظام تصميمها وتجربة المحرر. أما منطق كل شاشة وعقدها فمن الوحدة المعنية.

## اصطلاحات موحّدة بين الوحدات

| الموضوع | الاصطلاح |
|---|---|
| معرّف المستأجر | البادئة `t_` |
| API التطبيق | `/api/app/v1/t/{tenant}/...` |
| API اللوحة | `/api/v1/tenants/{tenant}/...` |

| أسماء الجداول | البادئة `zid_` محجوزة لـ M10 |
| مقارنة التباين | تطبيق مرجعي واحد في الخادم (M02). وزر الإصلاح في اللوحة يستدعي `validate` |

## تصحيحات مطلوبة أثناء المراجعة

كُتبت المواصفات بالتوازي، فبقيت فروق صغيرة. كل بند هنا جزء من مهمة مراجعة الوحدة المعنية (REV-xx):

- **M06**: مسارات `/app/v1/push/...` تصبح `/api/app/v1/t/{tenant}/push/...`.
- **M11**:
  - مسارات اللوحة وحقل الخطأ تتبع M12.
  - `zid_imports` و`zid_section_*` تصبح `theme_imports` و`theme_section_*`.
  - إضافة `beauty` و`kids` و`home` و`sports` إلى `presets.sector`.
- **M13 وM14**:
  - `/api/v1/merchant/...` تصبح `/api/v1/tenants/{tenant}/...`.
  - إضافة مفاتيح M01 إلى `tenant.defines.json`، وهي `STORE_DOMAIN` و`STORE_ID` و`APP_STORE_ID` و`APPLICATION_ID_ANDROID` و`SUPPORTED_LOCALES` و`DEEP_LINK_HOSTS` و`DEFAULT_FLAGS` و`SNAPSHOT_VERSION`.
  - لقطة مضمّنة موحدة، وخيار `--offline` لأداة `tenantize`.
- **M15**:
  - النشر عبر `releases` الذري من M11.
  - تسجيل استخدام Ajv بدل zod لنماذج الكتل، و`@dnd-kit/react` بدل `@dnd-kit/core`، كملاحظة على ADR-0010.
- **M01**: الحقل `service` في استجابة الأعلام، وتركيب `storefrontErrorWidgetBuilder`.
- **M03**: مفاتيح `x-ui` التي تحتاجها اللوحة، وهي `widget` و`delivery_path` و`image.slot` و`visible_if` و`allowed` و`locked` و`catalog_group`.
- **M08**:
  - أربعة أحداث من M03: `block_item_impression` و`block_render_error` و`action_unhandled` و`block_data_refetch`.
  - endpoint لإحصاءات النوافذ المنبثقة مع ENG-10.
- **M10**: تأكيد الواجهة `CatalogReader` والحدث `CatalogChanged` المعرّفين في M11 §5.3.
- **M04**: البحث العربي الذكي (F-S18، Should) يُسند إلى M04 في المرحلة الثانية.
